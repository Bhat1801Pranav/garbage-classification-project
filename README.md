
# Garbage and Waste Classification Using Deep Learning

## Project Overview
An AI-based waste classification system using transfer learning
to classify waste images into six categories.

## Waste Categories
- Cardboard
- Glass
- Metal
- Paper
- Plastic
- Trash

## Technologies Used
- Python
- TensorFlow and Keras
- EfficientNetB0
- NumPy, Pandas, Matplotlib, Seaborn
- Scikit-learn
- Google Colab
- Gradio

## Current Results
- Validation accuracy: 88.71%
- Weighted F1-score: 0.89
- Model saving and reloading: successful
- Image-upload prediction demo: working

## Dataset
TrashNet dataset containing six waste categories.

## How to Run
1. Open `361.ipynb` in Google Colab.
2. Set up the required dependencies.
3. Mount Google Drive and configure the dataset paths.
4. Run the notebook cells in order.
5. Launch the Gradio interface.
